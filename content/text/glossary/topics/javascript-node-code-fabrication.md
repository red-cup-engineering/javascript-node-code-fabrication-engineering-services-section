# Javascript Node Code Fabrication

Javascript Node Code Fabrication is a domain within Javascript Code Fabrication, concerned with the fabrication of JavaScript code targeting the Node runtime specifically.

`node-js-packages-engineering-services-section` fabricates a complete JSNode operation package only after staged import, command, help, test, syntax, and pack assays pass.

[The CapCell PDK](https://github.com/red-cup-engineering/semiotic-computer-system-capability-cell-process-design-kit-engineering-services-section) fabricates a deployable capability-cell bundle — kernel, schemas, package, repository, wallet, web identity, receipts — from a package.json manifest and a capcell-spec.json.
